# HTML in Markdown Format

一个VS Code扩展，用于在Markdown文件中格式化HTML代码。

## 功能特性

- 在Markdown文件中格式化HTML代码
- 支持选中部分格式化或整个文档格式化
- 使用`htmlfy`库进行HTML美化
- 保持原有的Markdown结构不变

## 如何使用

1. 打开一个Markdown文件
2. 选中需要格式化的HTML代码（可选，如果不选中则格式化整个文档）
3. 按下 `Ctrl+Shift+P`（Windows/Linux）或 `Cmd+Shift+P`（macOS）打开命令面板
4. 输入并选择 "Format HTML" 命令
5. HTML代码将被自动格式化

## 要求

- Visual Studio Code 1.100.0 或更高版本

此扩展当前不添加任何VS Code设置。
